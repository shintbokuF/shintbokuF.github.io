AI ヘルプデスク基盤AI Helpdesk Platform

Production 2 months Full-stack

5,000人規模の商社向け AI ヘルプデスク基盤を、2か月で設計・開発し、本番導入。 顧客との要件整理、デモ、ミーティングをリードし、フィードバックを約70回の改善へ反映しました。 Next.js / Python によるフルスタック開発から Azure App Service (Web Apps) を中心としたインフラ構築まで担当。 UX/UI を再設計して7つの主要コンポーネントを実装し、ストリーミング応答の体感速度・状態表示を改善。チケット管理システムとの API 連携も実現しました。導入効果として、対応時間約60%、人件費約30%の削減を見込んでいます。
